# Задачи на неделю — планировщик

**Задачи на неделю** — самостоятельный тёмный планировщик Carbon+ для Windows. Основной экран показывает **семь колонок дней слева направо**, а выходные выделены отдельно. Без рекламных блоков и общей прокрутки экрана. Не требует регистрации, сервера и подписки.

## Установка на Windows

1. Скачайте [**install_nedelnik.bat**](https://github.com/alialooon/nedelnik/blob/main/install_nedelnik.bat) — на странице файла выберите **Download raw file**.
2. Запустите скачанный установщик двойным щелчком. Требуется установленный [Git for Windows](https://git-scm.com/downloads/win).
3. После установки запускайте **Nedelnik** с рабочего стола либо через меню «Пуск» → Nedelnik.

Установщик нужен только для первого запуска и обновления самого лаунчера. Он загружает независимый репозиторий `alialooon/nedelnik` в `%LOCALAPPDATA%\Nedelnik\source` и устанавливает **`%LOCALAPPDATA%\Nedelnik\NedelnikLauncher.exe`**.

Рабочий стол получает **обычный ярлык Windows `Nedelnik.lnk`** с иконкой календаря и часов. Ярлык запускает **непосредственно `NedelnikLauncher.exe`**, без PowerShell или командных скриптов. В лаунчере можно открыть планировщик, проверить обновления из GitHub и открыть папку приложения. Планировщик теперь открывается **в собственном окне Windows со значком календаря и часов на панели задач**, используя Microsoft Edge WebView2 Runtime (встроенный браузерный движок). Обновления страниц приложения скачиваются автоматически при открытии лаунчера, но им можно пользоваться и без интернета.

Личные планы, созданные **в новом встроенном окне**, сохраняются локально в `%LOCALAPPDATA%\Nedelnik\webview-profile`. **Предыдущие задачи никуда не удаляются:** они остались в старом браузерном профиле `%LOCALAPPDATA%\Nedelnik\browser-profile`. Если в новом окне задачи пока не видны, нажмите в лаунчере **«Старые задачи: открыть в браузере»**, экспортируйте задачи в JSON и импортируйте их через кнопку «Импорт» в новом окне. Профили нельзя объединять простым копированием файлов. Приложение не использует никакие файлы или настройки Crypto Screener.

**Если остались предыдущие ярлыки `Недельник.lnk`, запускавшие PowerShell**, не восстанавливайте их из карантина антивируса. Используйте новый ярлык `Nedelnik.lnk`, созданный установщиком. Не добавляйте обнаруженные угрозы в исключения антивируса. Новый исполняемый файл не имеет цифровой подписи, поэтому Windows SmartScreen или антивирус могут запросить дополнительную проверку; при обнаружении угрозы остановитесь и сообщите о ней.

**При повторной установке:** сначала при наличии задач сделайте экспорт в JSON. Новый установщик сохраняет старый репозиторий в `%LOCALAPPDATA%\Nedelnik\source-before-nedelnik`, если исходная папка подключена к другому репозиторию. Существующий браузерный профиль с задачами не удаляется.

## Навигация и задачи

Интерфейс состоит из **трёх уровней**, между которыми можно переходить плавно:

- **Список недель**: обзор шести недель с количеством запланированных и завершённых дел.
- **Неделя**: семь вертикальных колонок от понедельника слева до воскресенья справа; суббота и воскресенье выделены другим оттенком.
- **День**: все задачи выбранного дня. Если задач много, они разбиты на страницы, поэтому прокручивать весь календарь не нужно.

**Стрелка назад** слева от заголовка возвращает: день → неделя → список недель. Нажатие на неделю или на дату открывает следующий уровень. Для перехода к другому периоду можно использовать стрелки или **нажать на сам диапазон дат** и выбрать нужную неделю в календаре.

**Чтобы добавить задачу**, нажмите на свободное место колонки нужного дня либо на кнопку «+ Задача» в подробном просмотре дня. В форме доступны:

- **Задача**: введите название или нажмите маленькую кнопку «≡» рядом с полем, чтобы выбрать готовую задачу из общего списка.
- **Категория**: Работа, Учёба, Личное время, Спорт, Здоровье. Категория «Другое» сохраняется ради старых записей.
- **Планирование**: интервал (начало–конец), необходимое время (часы и минуты) или количество повторений (план и факт).
- **Важность**: низкая (зелёный), обычная (стальной), высокая (коралловый).
- **Статус**: не выполнена, частично выполнена, выполнена. Быстро переключается нажатием на квадрат рядом с задачей.

Фактическое время можно указать отдельно; статистика «план / факт» суммирует минуты и показывает их в часах (90 минут = 1 ч 30 мин = 1,5 часа). Для повторяющихся по неделям задач фактическое время и статус хранятся отдельно для каждого появления. Частично выполненная задача учитывается в прогрессе как половина выполненной.

**«Общий список дел»** в меню «···» — только перечень сохранённых заготовок, без действий добавления прямо внутри списка. Чтобы создать заготовку, добавьте задачу на день и включите «Сохранить также в общий список» в дополнительных настройках формы. В другой день нажмите «≡» в форме задачи и выберите её из списка. Никакие копии не создаются автоматически.

Поиск, фильтры, заметка к неделе, статистика и экспорт/импорт резервных копий остаются доступными. Обе версии планировщика используют прежний ключ локального хранилища; ранее сохранённые задачи и заметки не стираются.

## Запуск без установки

Скачайте `weekly-planner/planner-standalone.html` и откройте в браузере.

Для разработки модульной версии из корня репозитория:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/weekly-planner/`.

## Данные и проверка

Задачи сохраняются локально в `localStorage` браузера, а не в GitHub. Между разными компьютерами и профилями автоматической синхронизации нет. Для резервного копирования используйте экспорт JSON.

Проверка логики при наличии Node.js 20+:

```bash
node --test weekly-planner/tests/*.test.mjs
```

Самодостаточный `weekly-planner/planner-standalone.html` автоматически собирается из `index.html`, `style.css`, `logic.mjs` и `app.js` командой `node tools/build-standalone.mjs`. Проверка согласованности: `node tools/build-standalone.mjs --check`.

Лаунчер и новое окно планировщика написаны на C# для Windows .NET Framework с Microsoft Edge WebView2 (зависимости берутся из официального NuGet-пакета при сборке). Код хранится в `windows/launcher/Program.cs` и `windows/launcher/PlannerWindow.cs`. Иконка хранится в `windows/launcher/nedelnik.ico`. Сборка и проверка выполняются GitHub Actions.

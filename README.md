# Недельник — планировщик дел на неделю

**Недельник** — самостоятельный русскоязычный планировщик на каждый день недели. Работает локально на компьютере без регистрации, сервера и облачной синхронизации.

## Установка на Windows

1. Скачайте [**install_nedelnik.bat**](https://github.com/alialooon/nedelnik/blob/main/install_nedelnik.bat) (на странице файла нажмите **Download raw file**).
2. Запустите скачанный файл двойным щелчком. Понадобится установленный [Git for Windows](https://git-scm.com/downloads/win).
3. После установки открывайте **Nedelnik.cmd** на рабочем столе (или в меню «Пуск» → Nedelnik).

Программа устанавливается в `%LOCALAPPDATA%\Nedelnik`, а исходники — в `%LOCALAPPDATA%\Nedelnik\source`. Файл запуска `Nedelnik.cmd` при каждом открытии пытается получить обновления из **этого репозитория**, а если интернет недоступен, открывает локальную версию. Для обновления и запуска используется обычный видимый командный файл Windows, без PowerShell, скрытых окон и обхода политики выполнения скриптов. Edge или Chrome открывает планировщик с отдельным профилем: `%LOCALAPPDATA%\Nedelnik\browser-profile`.

**При переходе с прежней установки:** сначала по возможности сохраните задачи кнопкой «Экспорт» в JSON. Установщик сохраняет старую папку исходников в `%LOCALAPPDATA%\Nedelnik\source-before-nedelnik`, если обнаружит другой Git-репозиторий. Папка профиля браузера не удаляется. Если задачи не появились после установки, воспользуйтесь кнопкой «Импорт» и сохранённым JSON-файлом.

**Если антивирус пометил старые ярлыки `Недельник.lnk`:** не восстанавливайте их из карантина и не добавляйте в исключения. Удалите старые ярлыки средствами антивируса или Windows и скачайте свежий `install_nedelnik.bat`. Новый установщик создаёт `Nedelnik.cmd`, а не ярлык, запускающий PowerShell. Любое новое предупреждение антивируса следует проверить, а не игнорировать.

## Запуск без установки

Скачайте `weekly-planner/planner-standalone.html` и откройте его двойным щелчком в браузере.

Для разработки модульной версии из корня репозитория запустите:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000/weekly-planner/`.

## Возможности

- Планирование с понедельника по воскресенье и переход между неделями.
- Задачи с временем начала и окончания, категорией, важностью и комментариями.
- Отметка выполненных задач, еженедельные повторения.
- Редактирование, удаление и кратковременная отмена удаления.
- Заметки на день и на неделю.
- Поиск, фильтры, статистика прогресса.
- Светлая и тёмная темы.
- Экспорт и импорт задач в JSON.

## Где хранятся задачи

Данные сохраняются **локально в браузере** (`localStorage`), а не в GitHub. Разные профили браузера и устройства не синхронизируются. Регулярно используйте «Экспорт» для резервной копии. JSON-файл может содержать личные заметки.

## Проверка логики

При наличии Node.js 20+:

```bash
node --test weekly-planner/tests/*.test.mjs
```

Технологии: HTML, CSS и JavaScript без сторонних библиотек и трекеров.

# Задачи на неделю — планировщик

**Задачи на неделю** — локальный планировщик для Windows. Новый интерфейс построен по принципу Ellie: слева **дела без даты**, справа **недельная доска**, отдельно **календарь с часовым расписанием**, режим фокуса и подведение итогов. Оформление **Soft macOS**: светлые многослойные поверхности, мягкие тени, голубые акценты, иконка календаря в стиле iOS и круглые кнопки. Режимы «Задачи», «Календарь», «Фокус» находятся в верхней панели, «Итоги дня» и «Аналитика» остаются рядом. Внешний вид оригинальный, без чужого исходного кода или фирменных ресурсов. Изменение темы не добавляет новых функций и не меняет данные. Не требует регистрации, сервера и подписки.

## Установка на Windows

1. Скачайте [**install_nedelnik.bat**](https://github.com/alialooon/nedelnik/blob/main/install_nedelnik.bat) — на странице файла выберите **Download raw file**.
2. Запустите скачанный установщик двойным щелчком. Требуется установленный [Git for Windows](https://git-scm.com/downloads/win).
3. После установки запускайте **Nedelnik** с рабочего стола либо через меню «Пуск» → Nedelnik.

Установщик нужен только для первого запуска и обновления самого лаунчера. Он загружает независимый репозиторий `alialooon/nedelnik` в `%LOCALAPPDATA%\Nedelnik\source` и устанавливает **`%LOCALAPPDATA%\Nedelnik\NedelnikLauncher.exe`**.

Рабочий стол получает обычный ярлык Windows **`Nedelnik.lnk`** с иконкой календаря и часов. Ярлык запускает **сразу сам планировщик** (без промежуточного стартового окна, PowerShell или командной строки) в собственном окне Microsoft Edge WebView2. При открытии локальный интерфейс загружается сразу, а обновления GitHub проверяются автоматически, без блокирования запуска. Если обновление скачано, страница обновляется без удаления локально сохранённых задач.

**Ручное обновление внутри программы:** откройте меню **`•••` → «Проверить обновления»**. Под пунктом отображается результат — проверка, актуальная версия, обновление или ошибка подключения. В обычном браузере пункт недоступен: он работает только внутри Windows-приложения, где имеется безопасное взаимодействие с Git.

**При переходе со старой версии со стартовым окном** один раз повторно запустите свежий `install_nedelnik.bat`, предварительно закрыв приложение. Это обновит установленный `NedelnikLauncher.exe` и ярлык. В дальнейшем обновления веб-интерфейса устанавливаются автоматически без переустановки.

Личные планы встроенного окна сохраняются в `%LOCALAPPDATA%\Nedelnik\webview-profile`. Данные **не удаляются при обновлениях**. Старый браузерный профиль `%LOCALAPPDATA%\Nedelnik\browser-profile` остаётся отдельно. Для доступа к нему при необходимости используйте команду `"%LOCALAPPDATA%\Nedelnik\NedelnikLauncher.exe" --old-tasks`; из открывшейся предыдущей версии можно экспортировать задачи в JSON и затем импортировать их в новом планировщике. Профили нельзя объединять простым копированием файлов. Приложение никак не связано с Crypto Screener.

**Если остались предыдущие ярлыки `Недельник.lnk`, запускавшие PowerShell**, не восстанавливайте их из карантина антивируса. Используйте новый ярлык `Nedelnik.lnk`, созданный установщиком. Не добавляйте обнаруженные угрозы в исключения антивируса. Новый исполняемый файл не имеет цифровой подписи, поэтому Windows SmartScreen или антивирус могут запросить дополнительную проверку; при обнаружении угрозы остановитесь и сообщите о ней.

**При повторной установке:** сначала при наличии задач сделайте экспорт в JSON. Новый установщик сохраняет старый репозиторий в `%LOCALAPPDATA%\Nedelnik\source-before-nedelnik`, если исходная папка подключена к другому репозиторию. Существующий браузерный профиль с задачами не удаляется.

## Интерфейс и возможности

**Список без даты (Brain Dump)** находится слева. Быстро добавляйте любые дела, а затем перетаскивайте их на нужный день. Перетаскивание задач работает и между днями.

**Задачи** — недельная доска с семью колонками, оценкой длительности, категориями и отметками выполнения. Кликните «Добавить задачу» в любой колонке. Стрелки в шапке переключают недели, а выбор даты позволяет сразу перейти к другой неделе.

**Календарь** — таймбокс всех суток от 00:00 до 24:00 без внутренней вертикальной прокрутки. Перетаскивайте задачи из списка на свободное время: программа назначит им конкретный час. События показаны цветными блоками по категориям.

**Планы на неделю и месяц** — сразу под навигацией находится компактная строка «Планы периода». Нажмите «Посмотреть», чтобы создать задачу **на выбранную неделю** или **на месяц выбранной даты** без назначения дня. В окне можно отмечать выполнение, редактировать задачу или кнопкой «На день» назначить конкретную дату. Также срок выполнения меняется в редакторе через «Когда выполнить» (день / неделя / месяц / без даты). Задачи на период не занимают часовые ячейки календаря и не дублируются по дням. В месячной аналитике месячные и недельные планы учитываются по одному разу; недельный план входит в аналитику соответствующей недели. Автоперенос просроченных дел не перемещает задачи на период.

**Фокус** — дела на выбранный день и таймер с длительностью **15, 25, 45, 60 минут или своим значением от 1 до 240 минут** (25 минут по умолчанию). Выбор сохраняется после перезапуска; при изменении длительности неактивный таймер сбрасывается на новый срок. Есть пауза и сброс. Можно выбрать конкретную задачу или запустить таймер прямо из её карточки. Каждая полностью отработанная минута автоматически добавляется в фактическое время задачи; для повторяющихся дел учитывается конкретная дата. При перезапуске приложения неполные минуты активной сессии не сохраняются.

**Итоги дня** — количество завершённых задач, плановое и фактическое время, текстовые выводы. Незавершённые разовые задачи можно перенести на завтра вручную. В меню **•••** есть необязательный **«Автоперенос невыполненного»**: после подтверждения, при открытии приложения или возвращении к его окну просроченные незавершённые разовые задачи переходят на сегодняшний день. Он **выключен по умолчанию** и сохраняет историю переносов; повторяющиеся и выполненные задачи не переносятся. **Аналитика** показывает неделю или месяц, прогресс каждого дня, план/факт и категории.

**Редактор задачи** поддерживает дату или отсутствие даты, длительность, фиксированный интервал, **цель по количеству повторений**, фактическое время, приоритет, категории и комментарии. В дополнительных параметрах — **подзадачи с отдельными галочками**, статусы (не выполнено / частично / выполнено), ежедневное, еженедельное, ежемесячное, по выбранным дням недели и через каждые N дней повторение. Для повторяющихся задач статусы, факт и выполненные подзадачи учитываются отдельно по каждой дате. При редактировании повторяющейся задачи изменяется вся серия; удалить одно отдельное повторение пока нельзя.

**Шаблоны**: создаются непосредственно в окне шаблонов или через «Сохранить как шаблон» в редакторе. Можно изменять название, категорию и длительность, добавлять копию в список без даты и удалять. Удаление шаблона не удаляет ранее запланированные дела.

**Корзина и копии**: в меню **••• → «Корзина и копии»** можно восстановить удалённые задачи и шаблоны в течение 30 дней, а также предыдущие локальные ежедневные снимки (до 7). Снимки создаются при первом изменении в день и остаются **в том же браузерном профиле** — это не защита от полной потери профиля, поэтому для важных данных периодически делайте **экспорт JSON**. Восстановление снимка заменяет текущее состояние, программа предварительно запрашивает подтверждение.

Экспорт и импорт JSON включают данные старого Недельника, задачи без даты и ежедневные итоги. Используется прежний ключ локального хранилища `nedelnik-planner-v1` — существующие задачи не сбрасываются.

### Ограничения текущей версии

Это самостоятельное приложение, **не официальный клиент Ellie**. Синхронизация с Google/Apple/Outlook Calendar, фирменный AI-ассистент и синхронизация между устройствами пока не реализованы. Планирование и календарь работают с локальными задачами. Данные хранятся только на этом устройстве; регулярно делайте резервные копии JSON.

## Запуск без установки

Скачайте `weekly-planner/planner-standalone.html` и откройте в браузере.

Для разработки модульной версии из корня репозитория:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/weekly-planner/`.

## Данные и проверка

Задачи сохраняются локально в `localStorage` браузера, а не в GitHub. Между разными компьютерами и профилями автоматической синхронизации нет. Для резервного копирования используйте экспорт JSON.

Проверка логики при наличии Node.js 20+:

```bash
node --test weekly-planner/tests/*.test.mjs
```

Самодостаточный `weekly-planner/planner-standalone.html` автоматически собирается из `index.html`, `ellie-style.css`, `logic.mjs` и `ellie-app.js` командой `node tools/build-standalone.mjs`. Проверка согласованности: `node tools/build-standalone.mjs --check`.

Лаунчер и новое окно планировщика написаны на C# для Windows .NET Framework с Microsoft Edge WebView2 (зависимости берутся из официального NuGet-пакета при сборке). Код хранится в `windows/launcher/Program.cs` и `windows/launcher/PlannerWindow.cs`. Иконка хранится в `windows/launcher/nedelnik.ico`. Сборка и проверка выполняются GitHub Actions.
